Creatio AI app development toolkit

Level: beginner

Building a Creatio app takes time: you set up data models, design pages, and add logic in multiple designers. Creatio AI app development toolkit lets you build Creatio apps by describing what you need in plain language. A coding agent does the work for you. Coding agents are AI tools that create and configure code from your instructions, for example, Claude Code, Codex, and GitHub Copilot. The toolkit teaches the agent how Creatio works, so you can build apps without deep technical skills.

Users and use cases​

You can use the toolkit regardless of your technical background.

No-code creators describe what they want to build in the agent chat and get a working app without writing code or working in designers. The more details they give, the better the result. To change an existing app, they describe the changes to the agent the same way.

Developers delegate routine tasks to the agent, such as creating objects, adding fields, and adding logic. The agent generates code and configuration, which leaves developers more time for complex work. They can also work with Creatio through the agent instead of the UI.

Toolkit components​

An AI model alone does not know how to build apps in Creatio. The toolkit gives the coding agent the knowledge and tools it needs to work in Creatio correctly.

The toolkit consists of the following components that work together:

  • a Creatio plugin and skills for the coding agent that guide agent behavior
  • MCP tools that let the agent work with Creatio directly, including Clio
  • supporting tools that the agent uses in its work, such as .NET SDK, Python, and Git
  • an installer that helps you install all needed tools and the Creatio plugin and skills

Clio is a command-line utility for managing Creatio configurations. Learn more: Install Clio (developer documentation).

With these components, the agent creates and configures apps without asking you to act at each step.

Application development capabilities​

After you set up the toolkit, the agent can take over the most time-consuming parts of app development. You can ask the agent to:

  • create complete web applications within the Creatio environment
  • build and modify data models that power application logic
  • name objects, columns, and lookups according to Creatio conventions
  • generate UI pages for web applications
  • design new Freedom UI pages and audit existing ones for usability and accessibility
  • create mobile pages and convert existing web pages to mobile pages
  • create the most commonly used business rules and logic
  • create business processes for Creatio 8.3.4 and later, including processes with branching, sub-processes, and script tasks, and help you test them
  • create and modify dashboards, home pages, desktops, and workplaces with analytical widgets of any type, including pivot tables
  • grant access permissions to dashboards, desktops, and workplaces
  • add and manage sections across existing or new applications
  • migrate Classic UI sections to Freedom UI
  • apply a brand theme, logos, favicon, and background that match the customer's brand
  • connect lookups and records to page fields
  • generate test data for development and validation purposes

For prompt examples, including dashboards, desktops, and home pages, see Working with coding agents in Creatio.

For advanced scenarios, the agent can also add validators and request handlers to Freedom UI pages. It can also apply a predefined set of business rules to automate page behavior. When no-code tools are not enough, the agent can add complex logic in code.

Supported agents and models​

We tested the toolkit with Claude Code, Codex, GitHub Copilot, and the Claude desktop app. Use the latest available model of your coding agent. You do not need Creatio credits to use the toolkit. You only need a subscription to your coding agent, for example, Claude or Codex.

note

For best results, use medium reasoning settings. They give the best balance: the agent writes correct code and follows the recommended approach.

To start using the toolkit, set up the local workspace using the Setup Wizard. Learn more: Set up Creatio AI app development toolkit.
