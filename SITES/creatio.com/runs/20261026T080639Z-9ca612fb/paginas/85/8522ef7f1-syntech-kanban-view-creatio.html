Syntech Kanban View for Creatio

by SYNTECH
5 (3)
Syntech Kanban View for Creatio is a visual element that streamlines record management by displaying items as cards organized into columns by stage. Features swimlanes, owner avatars, stage totals, progress bars, WIP limits, filters and DCM support.
Install

Overview

Product overview

Product description
This solution offers a user-friendly Kanban-style interface designed to simplify the way business processes are visualized and managed. It allows users to monitor workflow stages and interact with records directly on the board, eliminating the need to work through traditional list formats.

Key Features

Universal Kanban board

Configure a Kanban board for any section or page in the system, using any lookup field to define the stages. Effortlessly interact with records by moving them between columns via drag-and-drop.

Drag & Drop Layout Builder

Design card layouts visually by dragging fields into place and previewing the result instantly.

Custom Card Styles

Choose from multiple card styles, configure sorting, and display related data and subtasks.

Owner Swimlanes & Workload View

Split every stage by record owner to see individual workloads, card counts, and overdue items at a glance.

Configure in Minutes

Select any Creatio entity, choose the fields to display, and build your Kanban board without coding.

Easy Kanban Setup

Configure your own Kanban boards in just a few simple steps with flexible no-code settings.

Collapsible Board Columns

Collapse less important stages to keep large Kanban boards clean and focused without hiding your data.

Release summary
Live updates & performance:
Targeted card refresh. Record changes now update just the affected card (add / update / remove) instead of reloading the whole board. Full refresh happens only on the component's own auto-refresh interval.
Smarter server notifications. The board-refresh signal no longer fires a DB query on every save in the system — the set of Kanban schemas is cached — and is sent after commit, only for the changed record's schema.
Notify only when it matters. The server skips the refresh signal entirely for boards that have auto-refresh turned off (disableAutoRefresh).
Per-stage pagination
Independent column loading (opt-in). Each stage can now load its own pages from the server, so scrolling one column no longer pulls a global page full of other columns' cards.
Stable ordering. Explicit server sort (order column / sort column, with an Id tie-breaker) keeps pagination free of gaps and duplicates.
Faster board rendering: stage sorting and grouping are now memoized.
UI & data fixes
Stage/DCM case switcher no longer disappears after applying a filter or refreshing.
Top-right counter now updates correctly when a filter is applied (client + server filter logic unified).
Loading state on startup — the board shows a spinner while the license check runs, instead of briefly flashing a false "no license" message.

  3. Click New application. This opens a window.
  4. Select Install from file and click Select in the window that opens.
